1.2. Какие данные и зачем

Данные обрабатываются только чтобы работали функции сайта: комментарии, форум, личные сообщения, профили, лайки, модерация и защита от спама.

  • При входе через GitHub: идентификатор пользователя, GitHub-логин, имя и ссылка на аватар из вашего публичного профиля GitHub. Адрес электронной почты вашего GitHub-аккаунта передаётся сайту сервисом GitHub и хранится в системе входа (Supabase Auth); он нужен только для входа и идентификации и не показывается другим пользователям.

  • Социальные и игровые функции: заявки и связи с другими пользователями (друзья, «пары»), игровая статистика, результаты и вызовы в мини-играх, уведомления.
  • Служебные данные: время последней активности (индикатор «онлайн»), время создания записей, статус блокировки, если он применён.
  • Технические данные: IP-адрес и сведения о браузере, которые автоматически получают сервисы, перечисленные в п. 1.5 (в журналах серверов этих сервисов).

Специальные категории данных (здоровье, убеждения и т. п.) и биометрия сайтом не запрашиваются. Просим не публиковать такие сведения о себе и о других людях.

1.5. Где хранятся данные и кому они передаются

Важно знать. Основная база сайта (аккаунты, профили, комментарии, форум, личные сообщения, файлы) размещена в облачном сервисе Supabase. Его серверы находятся за пределами Российской Федерации. Нажимая «Согласен», вы соглашаетесь на передачу ваших данных на эти серверы.

  • GitHub Pages / GitHub — хостинг страниц сайта и вход через аккаунт GitHub. Правила: GitHub Privacy Statement.
  • Supabase — база данных, авторизация, файловое хранилище.
  • GoatCounter — счётчик посещений без cookie.
  • Браузерные уведомления — только если вы сами разрешите их в браузере; разрешение можно отозвать в настройках браузера.
  • Klipy — подбор GIF; при открытии поиска GIF туда отправляются ваш запрос и случайный идентификатор.
  • jsDelivr (CDN) — доставка скрипта библиотеки supabase-js; при загрузке получает ваш IP-адрес.

Мы не продаём данные и не передаём их третьим лицам в рекламных целях. Данные могут быть раскрыты государственным органам в случаях, предусмотренных законом.
